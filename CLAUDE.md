# CLAUDE.md: working guide for binder-docs

Read this before working in the repo. It records what the repo is, how it is
laid out, what exists, and what is missing.

## Big picture

This repo holds the printable templates for a **physical A4 ring binder**
(cover: "The Hellyers"). The binder is split into **7 sections**, each with
laminated sub-tabs. Every printed page is designed in **Scribus 1.6.3** and
exported to PDF.

The first commit **initialised the repository** with the user's uploaded files.
Nothing in that commit was generated by Claude.

## Rules

1. **`.sla.xml` is the master.** Change the Scribus source, then re-export the
   PDF. Never treat a PDF as the thing to edit.
   - Exception: `finance/budgets/budget-pages-1.pdf` is a **one-off with no
     source**. It was made in a browser, not Scribus. Keep it as a finished file.
2. **Folders follow the binder sections** (see the layout below). A new document
   goes in `<section>/<sub-tab-or-topic>/`.
3. **Images live in `assets/`**, grouped like the icon paths the Scribus files
   already use (`assets/finance/…`, `assets/home/…`).
4. **Don't fill in missing documents without asking.** The user will set out how
   they want to work on the gaps in a later step.

## File types

| Extension  | What it is                                          | Edit?               |
|------------|-----------------------------------------------------|---------------------|
| `.sla.xml` | Scribus 1.6.3 document (XML). This is the source.   | Yes                 |
| `.pdf`     | Exported print file. Some are fillable forms.       | No, re-export it    |
| `.png`     | Icons/illustrations used by the `.sla` files        | Lives in `assets/`  |

Scribus format notes (useful when reading or editing the XML directly):
- Page size is A4 (595.28 × 841.89 pt). Margins are 40 pt.
- Master pages: `Normal` and `cleaning page`. The `cleaning page` master holds
  the header bar and the `checklist.png` icon.
- Shared colour palette ("Autumn"): brown dark `#4A2A1A`, brown highlight
  `#AD7A4F`, copper `#9A5126`, cream base `#EAD7AD`, cream dark `#C2A679`,
  cream outline `#6C5641`, lens highlight `#A9C6CC`.
- Fonts: Latin Modern Mono 10 (headings), Latin Modern Sans 10 (body),
  DejaVu Sans (default).
- `PTYPE` 2 = image frame, 4 = text frame, 5 = line, 6 = shape. `PFILE` is the
  image path, relative to the `.sla` file. `ITEXT CH="…"` is the visible text.
- The "fillable" variants hold PDF form fields. Keep them in step with their
  plain twins.

## Layout

```
core/                 shared across the whole binder
  core-layouts.sla.xml            11 pages:
                                    p1  cover ("The Hellyers", two portraits)
                                    p2  section docs (goal + stored-document list)
                                    p3  section context ("Set up environment")
                                    p4–10 section dividers (Finance … Archive)
                                    p11 laminate tab labels
  core-layouts-cover.pdf          export of p1
  core-layouts-section-docs.pdf   export of p2
  core-layouts-section-context.pdf export of p3
  core-layouts-laminate.pdf       export of dividers + tabs (8 pages)
finance/budgets/
  budget-templates.sla.xml        Monthly, Yearly, Weekly ×2
  budget-pages-1.pdf              one-off (browser): Monthly, Yearly, Daily log Mon–Sun
home/cleaning/
  cleaning-docs-templates(.sla.xml/.pdf)            10 focus/task worksheets
  cleaning-docs-templates-fillable(.sla.xml/.pdf)   fillable version of the same
work/projects/
  projects-three-section.sla.xml  Projects page with 3 title/description blocks (no PDF yet)
assets/                           planned, not created yet (see Missing)
```

Worksheets in `home/cleaning/` (page order): Peggling, Hyperfocus, Create focus
prompt ×2, Priority list, Only ten steps, Time-blocking, Break it down, Task
break down, Set up environment.
