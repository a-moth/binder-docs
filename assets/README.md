# Assets

Icons are [Lucide](https://lucide.dev) (ISC licence; the licence line is kept in every SVG).
They are generated by `scripts/make-icons.py`. To change the colours or icons, edit that
script and rerun it. Don't hand-edit the output.

Layout: `assets/<area>/<icon>-<colour>.{svg,png}`, one folder per binder area. An icon
is duplicated into every area that uses it.

| Colour suffix     | Hex       | Meaning                                         |
|-------------------|-----------|-------------------------------------------------|
| `brown-highlight` | `#AD7A4F` | Autumn theme default for new icons; used on dividers |
| `section`         | per area  | Cardstock colour of the area (see below)        |
| `physical`        | `#C07D78` | Disability pride: physical                      |
| `neurodivergent`  | `#D8C68A` | Disability pride: neurodivergent                |
| `invisible`       | `#DEDAD0` | Disability pride: invisible / undiagnosed       |
| `psychiatric`     | `#8FAEBD` | Disability pride: psychiatric                   |
| `sensory`         | `#7F9E7C` | Disability pride: sensory                       |

Section colours: core `#B6BCC0` · finance `#5F6C42` · home `#715C4D` · health `#AE857F` ·
work `#8B7D78` · learning `#A3AF9F` · archive `#A08A75`. Resources and travel have no
cardstock colour yet, so they get no `section` variant.

Special variant: `work/list-checks-pride.*` is a Lucide icon drawn in brand ink (`#3A1A08`) on
diagonal stripes in disability-flag order (physical, neurodivergent, invisible, psychiatric,
sensory), using the brand pride colours, with a taupe (`#988C78`) outline. It's used for the Work
checklist. Add more in `PRIDE_TILES` in the script.

`custom/` holds the hand-made illustrations (not generated).
