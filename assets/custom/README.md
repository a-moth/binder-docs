# Custom illustrations

Not Lucide. Drawn by `scripts/make-custom.py` (SVG source + 1024 px PNG). Edit the
script and rerun it rather than editing the files.

| File | What it is | Used by |
|------|------------|---------|
| `mushroomvarious.*` | Ask Herby mark (five pride circles) on a cream circle with a tiny copper leaf. Vector remake of the user's pixel art | every master page and divider |
| `bigmushroom.*` | Lucide-style mushroom (Lucide has none). Outline in brand pride colours, flag order, over a taupe underlay so the pale stripes show on white | cleaning worksheets |
| `ask-herby-mark.png` | The user's original mark artwork (375 px), the geometry source | not linked |
